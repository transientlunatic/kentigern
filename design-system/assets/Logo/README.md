Fixed-colour SVGs; SVG shown through `<img>` cannot inherit colour, so there is a light and a dark version of each.

- `wordmark-light.svg`: lockup for light grounds. Name in `ink` (#2C1E10), tile in `primary` (#2D6A7F).
- `wordmark-dark.svg`: lockup for dark grounds. Name in `ink` (#F0EFEC), tile in `primary` (#5BB8D4).
- `mark-light.svg`, `mark-dark.svg`: the ripple tile alone, same inks.
- `favicon.svg`: the "DW" ligature in Parchment (#F4F2F0) on a `primary` (#2D6A7F) tile; works on any ground.

The name is converted to outlines from EB Garamond Italic (SIL Open Font License).
