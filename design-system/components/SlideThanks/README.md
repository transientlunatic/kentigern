Closing slide: thanks, the site address, a QR code to it, and a Glasgow footer.

Set "Thanks!" in `slide-title` (serif italic), one line of `slide-body` in `ink-muted`, and the address in `slide-ref`'s mono family at a larger size in `primary`. The QR code sits on a `panel` tile with `radius-lg`, modules in `ocean` (dark on light, which scanners need), error correction H, with a two-module quiet zone. Test it from a phone at the back of the room's distance before presenting.

The footer carries the one Glasgow reference, in `slide-ref` mono: the Wellington-statue traffic cone in `orange`, then "Glasgow · 55.86° N, 4.25° W". It is the only icon allowed on a slide; do not add others. Use the same footer on the title slide only if there is room beside the presenter lines.

The consumer provides nothing but the slide number. Do not put contact details on the slide other than the address.
