Personal wordmark: "Daniel Williams" in EB Garamond italic beside a teal ripple tile, with a "DW" ligature tile as the favicon.

Use the lockup (`assets/Logo/wordmark-light.svg` on light grounds, `wordmark-dark.svg` on dark) in headers and at the end of a talk. Use the mark alone (`mark-*.svg`) where there is only room for a square, and `favicon.svg` as the site and social avatar. The favicon's D and W are one ligature: the W's top-left serif runs into the top of the D's bowl (EB Garamond Italic, W tucked in by 0.25 em). Do not set DW as two separate letters. The name is outlined, so it needs no font installed; the files are fixed-colour because an image cannot inherit text colour.

Keep clear space equal to half the mark's height on every side. Minimum sizes: lockup 24px tall, mark 16px, favicon 16px. Do not stretch, recolour, outline, add shadows, or set the name in another face. Never use the mark as a bullet or divider; it appears once per page.
