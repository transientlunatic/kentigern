Line with nested credible-interval bands: the house pattern for posteriors and population fits.

Draw the median at 2.2px in the series hue, the 50% band at 0.3 opacity and the 90% band at 0.18, same hue, behind it. Label them 'credible', never 'confidence'. A prior or reference is `grey`, dashed at 1.5px. Axis titles read `Quantity / unit`, e.g. `m₁ / M☉`; log axes carry fine minor gridlines in `grid-fine`. No frame.

The consumer provides the median and band edges at each x. The preview's curve is an illustrative shape, not data. Needs d3 v7 and `assets/Charts/kentigern-d3.js`.
